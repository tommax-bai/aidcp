# AIDCP 产品全景

> 文档性质：产品意图与能力分区。本文不是实现进度表，不用“已实现/未实现”列表替代
> OpenSpec、代码和运行态。当前状态的核验方法见 [`README.md`](README.md)。

## 1. 产品定位

AIDCP 面向需要长期运营多个社交平台账号的小团队，把内容浏览、互动、创作、审批、发布、
入站消息和风险处置放进同一个可控工作流。

它不是“点一下就假定成功”的群控脚本。系统把平台页面事实、账号与环境绑定、任务状态、
人工授权和平台最终回执分层记录：无法定位、未被授权、执行不明确或平台未确认时，运营侧
应看到真实状态和可处理的下一步。

当前平台适配包含小红书、Facebook 和视频号相关能力；不同平台的可用动作与验证方式不
相同，不能把某个平台已支持的行为推断到另一个平台。准确能力以平台 registry、Edge driver、
OpenSpec 契约和运行时 capability handshake 为准。

## 2. 使用者与入口

| 使用者 | 主要入口 | 关注点 |
| --- | --- | --- |
| 客户/运营 | Edge 桌面客户端 | 环境、账号、人设、内容工作区、任务、审批和可处理异常 |
| 管理员 | Console 管理后台 | 跨客户配置、模型与角色、运行状态、内容与审计 |
| 运营协作 | 飞书 | 命令、通知、审批卡片和人工介入 |
| 工程/运维 | OpenSpec、日志、服务与数据库 | 契约、发布证据、故障定位和回滚 |

不同入口消费同一份 Cloud 真态。客户端或飞书“已受理”只表示 Cloud 接受请求，不等于 Edge
已经执行，更不等于平台已经确认。

## 3. 能力地图

### 3.1 环境、账号与身份

- 管理本机浏览器环境及其 Cloud 连接状态；
- 区分环境、平台账号、客户归属和人设绑定，缺少权威绑定时失败关闭；
- 按平台 capability 展示可用操作，不用离线猜测制造假绿；
- 支持账号暂停、恢复、限制、占用和需要重新鉴权等可解释状态。

### 3.2 浏览与互动

- Edge 从真实页面读取结构化卡片、详情、评论和通知事实；
- Cloud 依据人设、内容与风控逐动作决策浏览、点赞、收藏、关注、评论或跳过；
- 页面动作带前置守卫、后置验证和有界重试；
- 平台限流、验证码、登录墙、目标缺失和结果歧义必须原样上报。

### 3.3 内容工作流

- 灵感/精选内容进入候选与改写流程；
- 文本、视觉、标题、话题和发布选项由分工角色处理；
- 待审稿支持人工查看和审批，编辑与审批需防止旧版本覆盖新版本；
- 立即发布、定时发布和平台结果对账使用不同状态，授权与实际发布分离。

### 3.4 任务与委托

- 客户端、Console 和飞书可以创建不同来源的任务；
- Cloud 负责选账号、排队、节奏、状态推进和持久化；
- Edge 通过 task lease 串行使用同一浏览器页面，不能让并发写任务互相踩踏；
- 暂停、取消、延后、失败、歧义和完成都要有可追溯原因。

### 3.5 入站互动管理

- 对支持的平台同步评论或私信等入站互动；
- Cloud 保存列表、规则、草稿、审核和发送账本；
- Edge 仅在授权、绑定和 capability 都成立时执行平台写入；
- `accepted`、`sent`、`confirmed` 和 `ambiguous` 保持不同语义，重试依赖稳定幂等键。

### 3.6 风控与人工接管

- Cloud `RiskController` 是账号最终风险状态的单写者；
- 配额、节奏、慢启动、去重、时间窗和平台风险信号共同约束动作；
- 高风险或不明确场景转人工处理，不伪造成功，也不静默扩大权限；
- 真实写入、共享账号和破坏性验证必须在明确目标与边界下执行。

## 4. 系统边界

- Edge 负责真实浏览器读取和动作执行，不承担全局规划、账号选择或最终风险状态写入。
- Cloud 负责权威业务状态，但不能把“命令已发送”推断为“平台动作完成”。
- Console 与飞书是操作入口和状态投影，不各自维护另一套审批或任务真态。
- Control repo 维护契约与流程，不包含三个应用仓的业务实现。
- 自动化测试、dev 部署和 ol 发布是三个不同完成层级，必须分别记录。

## 6. 如何判断当前状态

1. 用 `openspec list` 查看活跃 change，用 `openspec list --specs` 查看已合并行为契约。
2. 到 owning repo 确认默认分支代码、测试与 typecheck。
3. 运行态能力核对指定 dev/ol 目标的服务、health、日志、数据库和实际产物。
4. 真实平台动作只在有实际页面/账号证据时算真机通过；未完成项查看
   [`real-machine-acceptance-backlog.md`](real-machine-acceptance-backlog.md)。

不要用本文、日期 handoff、测试数量或历史部署记录回答“现在是否已经可用”。
