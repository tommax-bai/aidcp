## Context

从灵感库打开详情时返回栈为 `home → library`，再从详情进入参考创作页时栈变为 `home → library → detail`。现有 `goBack()` 只弹出一层，因此参考创作页左侧返回会回详情；右侧 `×` 当前对非详情页调用 `close()`，直接关闭整个内容工作区。

## Goals / Non-Goals

**Goals:**

- 参考创作页右侧 `×` 直接返回灵感库，不经过详情页。
- 复用现有列表恢复逻辑，保留分页、筛选与滚动位置。
- 参考创作页右侧 `×` 使用“返回灵感库”可访问名称。
- 左侧返回继续只退一层到详情，形成两个清晰不同的导航入口。
- 其它页面的关闭行为保持不变。

**Non-Goals:**

- 不移除或改变参考创作页左侧返回按钮。
- 不改变参考选项、排队请求、回执或稿件审核流程。
- 不改变详情页、灵感库或稿件审核的布局和样式。

## Decisions

### 返回灵感库前裁剪中间详情栈帧

新增局部 `returnToLibrary()`：查找返回栈中最近的 `library`，删除其后的中间页面，再调用既有 `goBack()`。参考创作页会先移除 `detail` 栈帧，然后由 `goBack()` 恢复列表；精选详情调用同一函数时无需裁剪。这样避免复制列表渲染、事件派发和滚动恢复逻辑。

### 详情与参考创作共享退出语义

标题配置将 `detail` 和 `create` 都视为“右侧按钮返回灵感库”的页面，并设置 `aria-label="返回灵感库"`。点击处理函数对这两个页面调用 `returnToLibrary()`，其它页面仍调用 `close()`。

### 左侧返回继续使用原栈

左侧返回按钮仍直接绑定 `goBack()`，所以参考创作页点击左侧返回时仍弹回详情。本变更不复用或重定向该按钮。

## Risks / Trade-offs

- [栈中缺少灵感库时无法返回] → 异常路径安全回退为关闭工作区，标准入口由测试覆盖。
- [裁剪栈可能破坏列表状态] → 只删除 `library` 之后的页面，并复用现有 `goBack()` 列表恢复路径。
- [同一 `×` 图形在页面间语义不同] → 每次配置标题都显式更新可访问名称，并覆盖返回列表后的恢复值。

## Migration Plan

纯前端导航变更，无数据迁移；回滚 JavaScript 与测试即可。
