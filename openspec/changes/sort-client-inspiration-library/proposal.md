## Why

客户灵感库目前只能按系统更新时间查看，无法优先找到点赞高、收藏高或综合热度高的参考内容。排序必须在当前账号和筛选条件下由 Cloud 在分页前完成，并保持缺失热度数据、分页总数和账号隔离的诚实语义。

## What Changes

- 为客户灵感库列表增加固定白名单排序：综合热度、收藏最多、点赞最多和最近更新；综合热度固定为 `点赞 + 收藏 × 1.43`。
- 由 Cloud 在当前账号及“未创作 / 已创作 / 全部”筛选后、分页前完成排序；只返回当前页，不把全池数据交给 Edge 排序。
- 不新增数据库加权列；使用整数化查询表达式计算综合热度，缺少点赞或收藏证据的内容排在有完整证据的内容之后，并以稳定次级字段避免分页抖动。
- 在客户灵感库筛选栏右侧增加低干扰排序下拉控件，提供公式说明、窄窗口换行、键盘操作、加载保留、失败回退和按环境恢复状态。
- 保持现有客户鉴权、环境到账号绑定、最小披露 DTO、详情和参考创作行为不变。

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `client-customer-auth`: 客户精选列表接口接受固定排序参数，并在账号隔离和一致分页边界内完成服务端排序。
- `edge-companion-ui`: 客户灵感库增加清晰、可访问且按环境恢复的排序控件及加载/失败交互。

## Impact

- `aidcp-cloud`: `CuratedContentStore.listForClient` 排序类型与 SQL、客户鉴权查询参数校验、存储和路由测试。
- `aidcp-edge`: Electron 主进程 IPC 白名单、渲染层环境状态、灵感库工具栏 DOM/CSS、交互和安全回归测试。
- `aidcp`: 修改 `client-customer-auth` 与 `edge-companion-ui` 契约并记录跨仓任务和验证。
- PostgreSQL：无表结构迁移、无持久化加权列、当前规模不新增表达式索引。
- 部署：Cloud 默认只部署到 `dev`；本变更不构建或发布 Edge 安装包。
