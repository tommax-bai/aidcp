# adspower-desktop-env-picker — 规格增量（edge-companion-ui）

## ADDED Requirements

### Requirement: 配置面板收进设置抽屉、稳态首屏不常驻表单
浏览器配置面板（provider 切换 / AdsPower 探测 / 环境列表 / 分身 ID / API 地址 / API Key）SHALL 整体收进齿轮开合的设置抽屉；稳态首屏 MUST NOT 常驻任何配置表单或「必填」字样。既有探测 / 拉取 / 手填兜底 / 保存并入启动 / 「按新设置重启」等要求在抽屉内 SHALL 原样成立。

#### Scenario: 稳态首屏无配置表单
- **WHEN** 配置齐备且应用处于稳态（运行 / 就绪 / 暂停）
- **THEN** 首屏不出现配置表单与「必填」标记，点击标题带齿轮可打开设置抽屉完成全部既有配置操作

#### Scenario: 待配置时主动步骤引导开抽屉
- **WHEN** 状态为待配置（如 AdsPower 模式缺分身 ID）
- **THEN** 首屏呈现一条醒目的主动引导（而非灰色告示），点击即打开设置抽屉定位到配置项

### Requirement: 恰好一个环境时自动选中
探测就绪并拉取环境列表后，若恰好存在一个环境且当前分身 ID 为空，桌面外壳 SHALL 自动选中该环境并明示「已自动选中」；存在多个环境或分身 ID 已有值时 MUST NOT 自动改写用户选择。

#### Scenario: 唯一环境自动选中
- **WHEN** 拉取到恰好 1 个环境且分身 ID 为空
- **THEN** 该环境被自动选中、分身 ID 自动带出，界面明示已自动选中，无需用户手动点选

#### Scenario: 多环境不代选
- **WHEN** 拉取到 2 个及以上环境
- **THEN** 不自动选中任何一个，等待用户点选（不替用户做多选一决定）

#### Scenario: 已有分身 ID 不被覆盖
- **WHEN** 分身 ID 已有值（历史保存或手填）
- **THEN** 自动选中逻辑不改写现值，仅照常高亮匹配的环境行
