## ADDED Requirements

### Requirement: 已确认零环境时环境栏 SHALL 提供专用首次创建空态

当权威运行花名册已确认为零时，左侧环境栏 SHALL 保持展开并显示“创建第一个运行环境”的占位按钮，SHALL 隐藏平台筛选、运行汇总、批量人设和全部启动/关闭等对零环境无意义的操作。占位按钮 MUST NOT 使用真实环境行、平台头像、状态点、环境 ID 或“离线”文案；点击 SHALL 直接打开环境管理的“新建环境”页。

#### Scenario: 首次零环境只展示有效下一步
- **WHEN** 权威运行花名册已确认为空
- **THEN** 环境栏保持展开，显示“创建第一个运行环境”占位按钮
- **AND** 平台筛选、运行汇总、批量人设和全部启动/关闭不显示
- **AND** 占位按钮不呈现平台或运行状态

#### Scenario: 首次占位按钮直达新建环境
- **WHEN** 用户点击零环境占位按钮
- **THEN** 环境管理浮层打开并激活“新建环境”页
- **AND** 用户无需先经过空的“环境”列表

#### Scenario: 筛选结果为空不冒充首次空态
- **WHEN** 运行花名册至少有一个环境但当前平台筛选结果为空
- **THEN** 环境栏保留平台筛选并显示“暂无该平台环境”
- **AND** MUST NOT 显示“创建第一个运行环境”占位按钮或隐藏整个批量操作框架

#### Scenario: 第一个环境加入后恢复正常环境栏
- **WHEN** 第一个环境创建或加入成功并进入权威运行花名册
- **THEN** 首次空态立即退出，平台筛选、汇总和适用的运行操作恢复
- **AND** 新环境作为真实环境行按权威状态显示，未启动时如实显示为离线

### Requirement: 已确认零环境时主工作区 SHALL 提供完整首次引导

当权威运行花名册已确认为零时，客户端 shell SHALL 隐藏所有依赖当前环境的身份、平台、代理、发布、进展、浏览器和自动化操作，并在右侧工作区展示与左侧空态一致的首次创建引导。引导 SHALL 说明“创建环境 → 登录账号 → 开始运行”的使用路径并提供唯一“创建运行环境”主按钮；MUST NOT 展示旧环境信息、零值工作区、可操作生命周期按钮或 `environment_not_owned` 等内部原因码。

#### Scenario: 零环境整页只保留可信全局能力和创建路径
- **WHEN** 权威运行花名册已确认为空
- **THEN** 标题栏只保留应用标识、全局 Cloud 环境和设置入口，并使用中性首次使用标题
- **AND** 当前环境身份、平台、代理、运行状态、发布、今日进展、活动流、开发者详情、浏览器和自动化操作不显示
- **AND** 右侧展示“创建环境 → 登录账号 → 开始运行”的引导及“创建运行环境”主按钮
- **AND** 页面 MUST NOT 显示旧环境名、平台徽标、零值进展或内部错误码

#### Scenario: 右侧主按钮直达既有创建页
- **WHEN** 用户点击右侧首次引导的“创建运行环境”按钮
- **THEN** 环境管理浮层打开并激活“新建环境”页
- **AND** 左栏创建卡、栏头管理和右侧主按钮共享同一创建流程

#### Scenario: 创建回执不提前伪造已就绪工作区
- **WHEN** 创建请求返回但第一个环境尚未进入权威运行花名册
- **THEN** shell 继续显示首次引导，不展示环境级工作区或运行按钮
- **AND** 只有真实花名册出现环境后才恢复正常标题栏、工作区和生命周期控制

#### Scenario: 引导支持键盘和减弱动态效果
- **WHEN** 用户用键盘浏览首次引导或系统启用减弱动态效果
- **THEN** 创建主按钮可聚焦、可触发且有可见焦点样式
- **AND** 三步路径不依赖动画才能理解，MUST NOT 自动抢夺用户焦点

#### Scenario: 首次引导保持明确视觉主次且不伪造进度
- **WHEN** 零环境引导显示在受支持的桌面窗口中
- **THEN** 右侧主卡靠近内容区上方，左侧占位入口作为低强调辅助导航
- **AND** “创建运行环境”是整页唯一高强调主操作
- **AND** 页面 MUST NOT 使用没有真实状态依据的分段色条冒充加载或完成进度
- **AND** 三步说明使用简洁完整的短句，在支持宽度内不得出现孤立单字换行
