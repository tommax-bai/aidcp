## Context

当前 renderer 已在运行花名册为空时强制展开左侧环境栏，并渲染“＋ 添加第一个环境”；但空态仍保留平台筛选、零值汇总和禁用的全部启动/关闭按钮，且占位入口调用 `openEnvAddPanel('join')`，先进入没有成员的“环境”页。环境管理浮层已统一承载加入、新建和代理配置，创建能力及安全门禁完整，本变更只重排 renderer 信息层级和入口路由。

环境栏的权威空态继续来自 `railEnvList()` 的完整运行花名册，而不是当前平台筛选结果、DOM 行数或 AdsPower 探测结果。创建成功仍以现有主进程回执、花名册落盘和 fleet 快照为准；UI 不提前构造虚假环境行。

## Goals / Non-Goals

**Goals:**

- 让已确认零环境的新用户一眼看到唯一下一步，并直接进入创建页。
- 仅在全量运行花名册为零时隐藏无效的筛选、汇总和批量运行区域；筛选结果为空但仍有其他环境时保持现有能力。
- 让环境管理导航和新建表单具备清晰的标题、字段、渐进式代理配置和底部主操作层级。
- 保持加载、失败、创建中、成功和失败口径诚实且可测试。

**Non-Goals:**

- 不增加第二套 onboarding 状态机、主进程 IPC、Cloud API 或数据库字段。
- 不改变环境创建、客户归属、代理解析、Facebook 批量建号、花名册落盘或运行生命周期语义。
- 不把占位卡做成真实环境行，不赋予平台头像、状态点、离线状态或可启动 ID。
- 不重做环境列表、批量代理、设置抽屉或右侧业务工作区。

## Decisions

### 1. 用全量运行花名册判定专用零环境态

`renderRail()` 继续以 `allList.length === 0` 作为 `rosterEmpty`，并把该布尔值放入渲染签名和环境栏类名。CSS 仅在该类名存在时隐藏平台筛选、Facebook 批量人设、汇总、收起按钮、收起态管理入口和栏尾运行操作；当前平台筛选结果为空但 `allList` 非空时仍渲染筛选器与“暂无该平台环境”。

不用 AdsPower 列表、当前筛选行或 DOM 数量判空，因为这些值可能处于读取中、失败或局部筛选状态，不能代表客户确实没有运行环境。

### 2. 占位卡是创建按钮，不是虚构环境

空态按钮保留在 `rail-list` 内，但使用加号图形、主标题“创建第一个运行环境”、辅助说明“创建后可在这里切换账号并查看运行状态”。它没有 `.rail-row`、平台色、状态点或环境 ID，点击直接调用 `openEnvAddPanel('create')`。

栏头“管理”仍保留作为已有环境/高级入口；零环境时点击它也直达创建页。这样主入口不绕路，同时没有删除加入已有环境的“环境”页。

### 3. 环境管理使用文字页签和纵向创建表单

浮层头增加简短副标题，页签改为内容宽度文字导航和底部激活线，不再把两页伪装成并列主按钮。新建页按“选择平台 → 浏览器系统 → Facebook 条件字段 → 代理设置 → 创建回执”排序：

- 平台仍使用现有 `select` 值和事件链，视觉上包装为具名字段，不新增平台状态源。
- 操作系统使用全宽字段；Facebook 批量模式继续隐藏该字段并由主进程随机分配。
- 代理默认显示“无代理（可稍后配置）”摘要；选择非 `no_proxy` 或展开按钮后才呈现结构化代理字段。Facebook 批量代理继续按原条件显示。
- “创建环境”从字段行移到底部动作区，成为唯一蓝色主按钮；取消只关闭浮层，不修改输入。

优先复用现有 DOM ID 和事件监听，避免改 IPC 和测试桩；新增包装结构、辅助文案和 CSS class，不复制创建逻辑。

### 4. 创建反馈保持现有回执权威并补齐交互锁

创建期间给新建页加 `is-creating` 状态、禁用页签切换/关闭/重复提交，并让按钮显示“正在创建…”；创建完成后按现有回执更新花名册和列表。单个成功后切回“环境”页，使新加入的离线环境可见；批量或部分失败保留当前页及输入/错误，避免用户丢失核对上下文。

若实际创建请求无法取消，遮罩点击和 Escape 在 `is-creating` 期间不关闭；这只是一层 renderer 交互锁，不声称请求具备取消能力。

## Risks / Trade-offs

- [隐藏栏尾后空态卡可能显得过高] → 空态列表使用紧凑居中卡，不改变有环境时固定高度和滚动规则。
- [CSS 包装影响 Facebook 条件字段] → 保留全部既有 ID、`hidden` class 和 `updateFacebookImportVisibility()`，测试单个/批量两种 DOM 可见性。
- [创建成功立即切页可能掩盖批量回执] → 只对确认成功的单个创建切回环境页；批量和任何失败留在创建页。
- [零环境与读取失败混淆] → 零环境只看权威运行花名册；AdsPower 探测/列表失败仍在浮层中显示错误，不参与环境栏判空。
- [弹窗变宽或内容变高] → 保持 620px 现有宽度和 `max-height` 内滚，不引入新的桌面窗口尺寸假设。

## Migration Plan

1. 新增 renderer DOM/CSS 和空态路由测试，再调整样式与交互。
2. 在独立 `aidcp-edge` worktree 运行聚焦 Electron 测试、完整测试和 typecheck。
3. 回写提交与验证证据，严格校验 OpenSpec，串行 fast-forward 到 `aidcp-edge/master` 并推送。
4. 本变更不改服务器运行时，不部署 dev/ol，不构建安装包；源码回滚为回退 Edge 提交。
