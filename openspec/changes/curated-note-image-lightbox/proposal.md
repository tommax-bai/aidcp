## Why

精选内容池列表里的图片缩略图已经是站内浮层预览，但「查看笔记」详情里的参考图仍会按原图链接打开，可能触发浏览器下载或离开当前操作上下文。运营查看笔记时需要和列表一致的图片预览体验：点击图片只看图，不下载、不跳转。

## What Changes

- 将精选内容池「查看笔记」详情中的参考图点击行为改为打开站内图片预览浮层。
- 预览浮层复用列表图片交互，支持多图上一张 / 下一张切换，并显示当前位置。
- 参考图点击不再导航到原图 URL，也不使用下载入口；缺图仍按现有空态诚实呈现。

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `panel-curated-content`: 明确精选内容池列表与查看笔记详情中的参考图均使用站内浮层预览，不直接打开/下载原图。

## Impact

- `aidcp-console`: 精选内容池页面组件、局部样式和页面测试。
- API / cloud / edge / 数据库：无变更。
