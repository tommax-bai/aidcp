## Adversarial review — resolved + deferred (2026-07-10)

4-dimension review (red-lines / receipts / wiring / selector-fidelity), each finding skeptic-verified:

- **[FIXED, critical]** like-executor `reactState` misclassified the reaction-COUNT-summary button (aria-label="赞" + numeric text "3,829") as an already-reacted toggle → like was a no-op on any post with existing reactions + false `already_liked` (and a latent silent-fake-success in VERIFY). Fix: numeric-text guard (mirrors feed-reader's `/\d/` guard) in both the in-page `reactState` and `isReactedState`; `fbText` now falls back to `textContent` (matches feed-reader/probe). jsdom regression test drives the real IIFEs against a realistic action bar (count button in DOM before the toggle) and proves the toggle is selected + clicked + verified. (edge 4c9ce61)
- **[FIXED, major]** FB overlayMonitor was started but not wired to the cloud captcha/throttle report gate → FB captcha/soft-throttle never escalated (no `risk.captcha_detected`), defeating the account-nurture throttle-backoff (cloud facebook-throttle-signals depends on this signal) and remote captcha assist. Fix: reused the xhs overlay-report-gate + WatcherSupervisor wiring for FB (unknown delayed-confirm / captcha immediate fail-closed / detected-cleared paired), and lifecycle-managed the monitor (stop on CDP-unrecoverable, no orphan polling). (edge 4c9ce61)
- **[DEFERRED → real-machine backlog, major]** No IdentityWatcher on the FB browse path → a long-running FB session logged out mid-loop does not self-heal (feed/post readers honestly return login_required per command; cloud watchdog + operator restart recover). Rationale for deferral: pre-existing FB gap (the FB comment-only path also lacked it); NOT a red-line (receipts stay honest, no fake success); the loop ships default-off + shadow-first + operator-supervised in isolation; a correct fix needs FB-aware identity self-heal (FB login-wall confirmation, not the xhs CdpLoginModalWatcher) and carries the identity-watcher false-positive-brick risk (memory identity-watcher-false-positive-brick) — must be designed, not rushed.
