## MODIFIED Requirements

### Requirement: 分身 id 默认由选中环境带出、手动填写为可切开关

`adspower` 模式下，分身 id **默认不需要手敲**。多环境模式下，环境列表 SHALL 支持**多选**：运维可勾选一个或多个环境加入**运行花名册**，每个花名册成员 SHALL 各自携带其环境的 `user_id`（只读呈现）作为该环境将写入的分身 id；花名册 SHALL 持久化为一个环境列表。桌面外壳 SHALL 另提供「手动填写」开关，**默认关闭**（此时分身 id 取所选环境的值）；打开后 SHALL 呈现手敲输入框作为兜底（列表拉不到等场景，用于加入单个环境）。无论来自选中还是手敲，加入 / 启动前 SHALL 校验每个成员的最终分身 id 非空，且写入的 SHALL 始终是环境的 `user_id`（非序号）；同一分身 / 账号 MUST NOT 被重复加入花名册（防 edgeId 撞车 / 串号）。既有单分身设置（`adsProfileId` 单值）SHALL 向后兼容加载为**单元素花名册**。分身 id 的只读展示、「手动填写」开关与手敲输入框，连同 API 地址、API Key，SHALL 默认折叠于「高级设置」中、点开才呈现；当探测未就绪或环境拉取失败等需要手动兜底时，桌面外壳 SHALL 自动展开「高级设置」使「手动填写」即时可达。

#### Scenario: 多选环境加入运行花名册
- **WHEN** 运维在环境列表勾选多个环境并加入
- **THEN** 每个被选环境成为花名册成员、各带其 `user_id`，花名册持久化为环境列表，各成员可独立启动 / 停止

#### Scenario: 重复加入同一分身被拦
- **WHEN** 运维试图把一个已在花名册中的分身 / 账号再次加入
- **THEN** 外壳诚实拦阻并提示已加入，MUST NOT 让同一分身 / 账号在花名册中出现两次（防 edgeId 撞车）

#### Scenario: 打开手动填写开关作兜底
- **WHEN** 运维打开「手动填写」开关
- **THEN** 面板呈现手敲输入框，运维可自行填分身 id 加入单个环境；关闭开关则回到取选中环境的值

#### Scenario: 旧单分身设置向后兼容
- **WHEN** 载入历史保存的单值 `adsProfileId` 设置
- **THEN** 该值被兼容加载为单元素花名册，既有单环境使用不受影响

### Requirement: 恰好一个环境时自动选中

探测就绪并拉取环境列表后，若恰好存在一个环境、运行花名册为空**且核心未在运行**，桌面外壳 SHALL 自动把该环境加入花名册并明示「已自动加入」；存在多个环境时 MUST NOT 自动替运维决定加入哪些——运维经**多选**把想跑的环境加入花名册。外壳 MUST NOT 在有环境正在运行时自动改写花名册（绝不在运行中偷改配置）。

#### Scenario: 唯一环境自动加入花名册
- **WHEN** 核心未在运行、花名册为空且拉取到恰好 1 个环境
- **THEN** 该环境被自动加入花名册、其分身 id 自动带出，界面明示已自动加入，无需运维手动勾选

#### Scenario: 多环境不代选、由运维多选加入
- **WHEN** 拉取到 2 个及以上环境
- **THEN** 外壳不自动替运维选择，等待运维多选把想跑的环境加入花名册

#### Scenario: 运行中不偷改花名册
- **WHEN** 已有环境在运行
- **THEN** 外壳 MUST NOT 自动改写花名册，任何增删由运维显式操作
