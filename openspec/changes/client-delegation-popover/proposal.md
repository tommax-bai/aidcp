## Why

客户端首屏当前把“交给 AIDCP”作为整张常驻卡片展示，挤占了陪伴视图中运行进展、发布结果和今日进展的纵向空间。委派是重要但按需使用的操作，应在保持入口可见、任务真态可达的同时，从主信息流中收进轻量浮层。

## What Changes

- 在首屏“当前状态 / 状态更新”区域最右侧增加小型委派入口，使用与现有客户端一致的交互蓝、圆角和线性图标。
- 移除主列中常驻的大号委派卡片，把原有目标数、执行窗口、优先级、快捷动作、刷新和真实任务进度完整迁入右对齐的锚定浮层。
- 浮层支持按钮再次点击、点击外部和 Escape 关闭，并在环境切换时关闭，避免把上一账号的操作上下文留在屏幕上。
- 浮层打开时刷新当前选中环境的委派任务；任务与确认仍沿用真实账号绑定、二次确认和诚实进度约束。
- 增加键盘、可访问状态、小窗口高度和内部滚动的回归覆盖，确保浮层不会重新挤压或遮死主界面。

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `edge-fleet-console`: 将当前选中环境的委派入口改为状态区右端的小图标，并规定委派内容由按需锚定浮层承载及其账号切换/关闭行为。
- `edge-companion-ui`: 扩展在场感行的交互布局与可访问约束，保证委派浮层不占主列常驻空间且适配窗口边界。

## Impact

- 代码：`aidcp-edge/src/electron/renderer/index.html`、`renderer.js`、`styles.css`。
- 测试：`aidcp-edge/test/electron/companion-ui.test.ts`。
- API / 协议 / 数据库：无变化；继续复用现有委派任务 IPC 与确认链路。
- 交付：客户端源码变更；按既有约定不自动构建或发布桌面安装包。
