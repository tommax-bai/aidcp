## Why

AIDCP 目前只验证了 TikTok For You/单视频浏览、一次点赞、评论只输入和发布前编排器；对照抖音调研后，多 surface 导航、关注/收藏/分享状态、消息/直播入口和回复语言边界仍缺少真实网页证据。需要继续以本地测试环境建立默认只读、证据可回查的差异探针，再决定是否进入正式平台接入。

## What Changes

- 新增 TikTok 网页端 CDP 交互探针，支持登录/挑战页识别、当前视频稳定标识、信息流滚动和滚动后内容变化验证。
- 新增一次性点赞探针：默认只读，只有显式动作开关打开且目标仍唯一匹配时才点击；已经点赞时不反向取消，点击后必须由同一视频的 UI 状态确认。
- 新增评论输入探针：只定位并填写当前视频评论编辑器，代码路径不包含提交点击或回车提交，并回读编辑器内容确认输入成功。
- 新增发布编排器探针：只读识别上传入口和表单结构，可用无敏感合成视频验证文件选择、平台上传确认和文案填写，硬性停在最终发布之前。
- 新增 Douyin 差异调研探针：盘点 For You、Following、作者主页、搜索、标签/音乐、消息、通知和直播入口；观察当前作品的关注、收藏和分享控件，但不点击、不选择分享对象。
- 新增回复语言安全证据：浏览器 UI locale 与账号对外写作语言分开报告；未显式配置回复语言与精确允许文本时，消息/评论/直播探针不得进入编辑器。
- 记录 TikTok 官方 Login Kit、Content Posting API、Display API 和发布状态回查的 readiness 边界，不读取或调用本地不存在的凭据，也不以网页最终提交作为回退。
- 探针输出脱敏的结构化证据，不读取或打印 cookie、token、原始账号标识、请求正文或其他敏感数据。
- 使用本地 AdsPower 环境 `k1eu5amn` 做受控真机验证；浏览和一次点赞可真实执行，评论停在已输入未发送状态，发布探针最多停在合成素材已暂存且编排器可提交状态。
- 本变更仅交付开发/验收探针，不把 TikTok 宣称为已接入的正式生产平台，也不修改 Cloud 风控、协议或自动运营调度。

## Capabilities

### New Capabilities

- `tiktok-cdp-interaction-probes`: 规定 TikTok 网页端浏览、受控点赞、评论只输入不发送、发布编排器只暂存不提交、Douyin 差异能力只读盘点、回复语言失败关闭、挑战页中止和脱敏证据的探针行为。

### Modified Capabilities

无。

## Impact

- 代码：`aidcp-edge` 新增 TikTok 交互、发布编排器和能力差异探针、手动运行脚本及聚焦测试。
- 运行环境：本地 AdsPower API 与 `k1eu5amn` profile；不访问 Cloud，不部署到 dev/ol。
- 协议/API：无生产协议变更，无数据库变更，无新增第三方依赖。
- 风险：TikTok 页面布局、语言和 A/B 实验可能导致探针诚实失败；验证码、登录失效、目标歧义或点赞后状态不明确时必须中止，不得推断成功。
