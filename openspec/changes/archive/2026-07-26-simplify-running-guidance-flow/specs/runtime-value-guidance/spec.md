## MODIFIED Requirements

### Requirement: 详细浏览步骤不得与价值进度争夺主视图

Edge 客户端 SHALL 让探索进度卡按状态职责展示信息：普通运行态 SHALL 以真实浏览进度和已确认灵感结果为主且 MUST NOT 展示三段流程；场次间隔、小时间隔、今日完成和首帖创作 SHALL 保留与状态匹配的三段价值流程。客户端 MUST NOT 在主视图或探索进度卡中提供“查看运行步骤”或“收起运行步骤”入口，也 MUST NOT 保留可展开的七段详细浏览步骤。

#### Scenario: 普通运行态只展示真实进度和已确认结果
- **WHEN** 探索进度卡处于普通运行中
- **THEN** 卡片不展示“浏览与互动 / 判断匹配度 / 继续寻找灵感”三段流程或连接器
- **AND** 卡片继续展示真实浏览进度、进度计数和无障碍进度语义
- **AND** 仅当 `dailyUsage.inspirationSummary` 提供大于零的真实数量时展示已记录灵感结果
- **AND** 缺少真实灵感汇总时 MUST NOT 用收藏数、候选数或“持续判断中 / 持续筛选中”补写结果

#### Scenario: 有阶段意义的状态保留三段价值流程
- **WHEN** 探索进度卡处于场次间隔、小时间隔、今日完成或首帖创作状态
- **THEN** 卡片展示与该状态匹配的三段价值流程
- **AND** 页面不存在“查看运行步骤”或“收起运行步骤”入口
- **AND** 页面不存在可展开的七段详细浏览步骤

#### Scenario: 动态连接线匹配卡片语义
- **WHEN** 三段价值流程之间展示动态连接线
- **THEN** 场次/小时间隔使用青色语义，今日完成使用绿色语义，首帖创作使用对应的阶段色
- **AND** 两条连接线分别作为独立连接器渲染，MUST NOT 依赖相邻阶段节点的伪元素或状态色完成着色
- **AND** 每条连接器的滑动圆点圆心从线段 `0%` 移动到 `100%` 后再复位，MUST NOT 只以圆点外框触碰端点冒充完整行程

#### Scenario: 新手首帖引导的创作连接线使用橙色语义
- **WHEN** 新手首帖引导展示“看趋势 → 找匹配 → 开始创作”三段流程
- **THEN** “开始创作”的图标、标题与其前方第二条连接器使用一致的橙色创作语义，MUST NOT 让连接器回退为灰色默认线
- **AND** 首轮搜索阶段的静态连接线与命中灵感后的动态连接线均保持橙色语义
- **AND** 宽屏横向布局与窄屏纵向布局使用相同颜色映射

#### Scenario: 三个阶段保持既有三等分节奏
- **WHEN** 探索进度卡展示三段价值流程
- **THEN** 三个阶段使用既有三等分阶段列，不因普通运行态移除流程而强行放宽或把第三阶段推至内容区尾端
- **AND** 第三阶段右侧保留原布局的呼吸空间
- **AND** 两条独立连接器覆盖在前两个阶段列尾部，MUST NOT 为占据额外网格列而改变三个阶段的位置
- **AND** 场次间隔、小时间隔、今日完成和首帖创作使用同一套三等分布局

#### Scenario: 运行态移除流程后保持清晰信息层级
- **WHEN** 普通运行态不展示三段流程
- **THEN** 价值说明与进度区之间使用轻量分隔和紧凑留白
- **AND** 已确认灵感结果使用克制的结果色，不新增卡片、徽章或动效
- **AND** 窄屏下进度标题、计数和结果仍完整可读且不保留空流程占位

#### Scenario: 时间走字不得把圆点反复重启在半程
- **WHEN** renderer 每秒刷新相对时间、阶段文案或接收同结构的状态推送，且当前状态展示三段价值流程
- **THEN** 三段流程的既有连接器节点继续复用，阶段内容在原节点更新
- **AND** 连接器处于同一活动状态时 MUST NOT 因周期刷新被替换或重新启动动画
- **AND** 圆点在多次周期刷新之间仍能完成从线段 `0%` 到 `100%` 的连续行程

#### Scenario: 普通运行态按区域迁移流光
- **WHEN** 获得感卡片处于普通运行态且 presence 事件仍在实时窗口内
- **THEN** 顶部动作状态区域只显示真实动作文字，MUST NOT 播放文字流光
- **AND** 下方创作方向标题区域播放文字流光，不依赖顶部动作文字的具体内容
- **AND** 事件的新鲜度、“刚刚更新”和活动指示继续由真实时间戳驱动
- **AND** presence 动作文案保持原样，MUST NOT 因流光区域迁移而被改写

#### Scenario: 获得感卡片吉祥物保持静止且不影响首次恭喜弹窗
- **WHEN** 获得感卡片展示运行、间隔、完成或首帖状态的任一吉祥物
- **THEN** 吉祥物图片保持固定，不播放位移、浮动或缩放动画
- **AND** 首次设立好人设后的恭喜弹窗继续播放既有一次性吉祥物动画
- **AND** `prefers-reduced-motion` 下恭喜弹窗仍按既有规则关闭动画
