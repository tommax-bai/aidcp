## Why

当前 `/publish`、`/comment`、精选行级动作和内容排期各自拥有一套触发、排队与回执语义，能完成单次操作，却无法诚实表达“在截止时间前完成 5 条已验证评论”这类用户业务目标。继续增加 slash command 会把账号解析、确认、人审、风控、优先级、暂停取消、去重和结果统计复制到更多入口，因此本阶段需要先建立统一的 `DelegatedTask` 领域模型，再让自然语言和快捷入口只负责生成同一种结构化任务。

## What Changes

- 新增持久化 `DelegatedTask` 模型、状态机和事件/进度账本，统一记录账号可读名、平台事实、动作、目标成功数、最大尝试数、截止时间/执行窗口、来源与目标约束、人审模式、优先级、暂停/取消语义和诚实终态。
- 新增“解析为草稿 → 结构化确认卡 → 明确确认 → 去重入队 → 安全边界执行 → 真实结果投影”的统一服务；所有公共写入口必须先确认，`successCount` 只接受平台验证成功，候选不足允许 `partially_completed`，不得换目标凑数或把尝试计为成功。
- 第一批动作覆盖：N 条有效评论、普通发稿、参考今日灵感发稿、对指定精选内容评论、生成多个候选稿但暂不发布、候选稿批准/驳回/修改，以及立即/定时/下一安全空档/优先执行、完成当前安全动作后暂停、取消剩余部分和进度查询。
- Edge 快捷入口绑定当前选中环境并显示任务确认/进度；Feishu 支持自然语言与旧命令语法并存，所有写命令统一先生成确认卡并必须用账号昵称唯一解析；精选内容行级写动作改为先生成可确认任务。
- 小红书作为完整首发平台。Facebook 只开放已有目标范围内的评论/群组任务、普通发布、审批和任务控制；能力注册表显式标注 Beta/闸状态，不承诺全站搜索、任意帖子 URL 评论或“今日灵感发稿”，也不新增通知、Inbox、私信、作者主页访问或关注。
- 单次旧命令在确认后保留现有人工触发/额度语义；批量、跨账号或异步委托一律走自动化额度，不得循环使用 `manualOverride` 绕过配额。`RiskController` 继续是风险状态唯一写者，公开评论/发布默认保留人审。
- 用户任务与现有 `PublishScheduler`、`CommentScheduler`、内容排期共享账号/平台 ownership、优先级和幂等键；抢占只消费租约层安全命令边界，不在本 change 另造协调器或修改在途点击/输入。
- 第二批长期规则只登记后续范围，不在本 change 实现：主题偏好/排除、文风与评论策略、每日频率、同作者频控、每日灵感总结、通知分类、规则持久化选择，以及规则版本/审批/撤销。
- 明确不做新平台、回复收到的评论、关键词私信、Facebook 通知/Inbox、自动隐藏/删除/封禁、Edge 安装包和 OL 部署。

## Capabilities

### New Capabilities

- `user-delegated-tasks`: 统一任务模型、确认、排队、执行 ownership、真实进度、暂停/取消、诚实终态及首批动作/平台边界。

### Modified Capabilities

- `feishu-command-ingestion`: 增加自然语言委托解析、昵称唯一解析、结构化确认卡和任务控制，同时保持现有 slash command 兼容。
- `edge-fleet-console`: 为当前选中环境增加委托快捷入口、二次确认与真实任务进度投影，不假设其他入口存在“当前环境”。
- `curated-note-actions`: 精选内容的参照创作与定向评论从直接触发改为创建待确认的委托任务，并继续保持账号归属与目标约束。
- `content-schedule`: 定时任务与用户委托任务共享 ownership、幂等和安全空档判定，禁止同账号同动作双重执行。
- `manual-command-override`: 将旧单次人工动作的额度豁免限定在单次命令，明确批量/异步委托不得继承或循环利用该豁免。
- `platform-runtime-abstraction`: 云端与边端注册表增加委托动作能力/受限状态，任务必须绑定账号平台事实源并 fail-closed 路由。

## Impact

- `aidcp-cloud`: 新增任务存储/服务/执行器、迁移、面板 API、Feishu 解析与卡片回调；接入账号存储、风险闸、现有发布/评论调度器和精选内容存储。
- `aidcp-edge`: Electron 主进程 HTTP 桥、当前环境快捷入口、确认卡与进度 UI；不改边云协议、不构建安装包。
- `aidcp-console`: 精选行级动作改为任务确认流程，并增加候选/任务真实状态展示所需的轻量 UI/API 接线。
- `aidcp`: 新增本 change 的 proposal、design、规格增量、tasks 与验证/部署记录。
- 部署只涉及 cloud 与 console 的 `dev`；Edge 源码完成后明确标注“安装端尚未发布”，不部署 OL。
