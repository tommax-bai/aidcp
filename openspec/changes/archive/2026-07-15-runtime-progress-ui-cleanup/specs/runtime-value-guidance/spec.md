## ADDED Requirements

### Requirement: 内部浏览步骤按需展开而非常驻占据主视图

Edge 客户端 SHALL 将详细浏览步骤作为运行价值说明的次级 disclosure 内容，MUST NOT 在在场感与运行价值卡之间常驻呈现为面包屑式流程轨道。默认主视图 MUST 优先展示当前价值说明、三段价值流程和真实进度；详细步骤展开后仍 MUST 使用真实浏览阶段点亮当前步骤。

#### Scenario: 带探索进度的运行价值卡默认保持主信息层级

- **WHEN** 运行价值说明因新鲜运行、本轮间隔或小时阶段而呈现实时或已记录的探索进度
- **THEN** 七段内部浏览步骤默认收起，主列中不出现独立常驻流程轨道
- **AND** 进度元信息附近提供低视觉权重的“查看运行步骤”入口

#### Scenario: 用户按需查看内部步骤

- **WHEN** 用户激活“查看运行步骤”入口
- **THEN** 客户端在运行价值卡内展开详细步骤，并将入口改为“收起运行步骤”
- **AND** 运行中的真实当前阶段继续被点亮，停止或非运行状态不得伪造当前步骤
