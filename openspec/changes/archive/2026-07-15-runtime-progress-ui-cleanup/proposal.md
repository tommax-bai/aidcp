## Why

主窗口同时常驻浏览阶段轨道、运行价值说明和今日进展三套进度表达，造成信息层级竞争；今日进展的独立圆形箭头也更像状态标签的下拉菜单，而不是控制整张进展卡的折叠入口。需要在保留运行透明度和既有数据真实性的前提下，降低内部流程与次要控件的视觉噪声。

## What Changes

- 移除主运行区上方常驻的六段浏览流程轨道，不再把内部工作步骤伪装成可导航面包屑。
- 将完整运行步骤降级为运行价值卡进度元信息旁的轻量“查看运行步骤”入口，保持可解释性但不与当前状态争夺首屏注意力。
- 将今日进展的独立圆形箭头改为带“展开 / 收起”文字和方向箭头的轻量 disclosure 控件，并让可访问名称与展开状态同步。
- 保持运行价值卡、发布结果、今日进展数据、会话控制和统计来源不变。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `runtime-value-guidance`: 运行价值说明承接可选的完整步骤入口，主界面不再常驻独立浏览流程轨道。
- `edge-companion-ui`: 今日进展折叠控件使用明确的展开 / 收起文字与方向状态，并保持低于生命周期主操作的视觉权重。

## Impact

- `aidcp-edge`: Electron renderer 的主区 DOM、运行引导元信息、今日进展折叠交互、CSS 与 UI 回归测试。
- `aidcp`: OpenSpec 变更记录与两项现有客户端呈现契约的增量规格。
- 不涉及边云协议、配额计算、浏览调度、发布审批或桌面安装包构建。
