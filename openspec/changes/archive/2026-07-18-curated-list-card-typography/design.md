## Context

灵感库卡片标题由 `.curated-card-top strong` 承载，状态标签由 `.curated-card-top em` 承载。当前状态标签与详情页 `.curated-detail-badge` 共用同一字号规则，因此直接放大共享规则会意外改变详情页徽标。

## Goals / Non-Goals

**Goals:**

- 建立列表标题 `16px`、摘要 `14px`、状态标签 `11px` 的清晰层级。
- 标题和状态标签使用已批准的跨平台字体栈。
- 保持标题单行省略和标签不收缩行为。
- 确保详情页徽标继续使用原有 `9.5px` 样式。

**Non-Goals:**

- 不调整列表摘要、作者时间元信息、卡片尺寸或图片尺寸。
- 不调整详情页标题、正文、话题、徽标或按钮。
- 不改变列表交互、分页、筛选或导航。

## Decisions

### 标题使用 16px 强字重

列表标题调整为 `16px / 700`，大于 `14px / 400` 的正文摘要，恢复标题优先级；继续保留现有单行省略与 `line-height: 1.4`。

### 拆分列表状态标签与详情徽标字号

共享选择器继续承载颜色、背景、圆角和内边距，字号分别由 `.curated-card-top em` 和 `.curated-detail-badge` 声明。列表标签使用 `11px`，详情徽标保持 `9.5px`，避免变更扩散。

### 复用完整字体栈

标题和列表状态标签复用正文已采用的完整跨平台字体回退链，使同一卡片内中英文与 Emoji 渲染一致，同时不向父容器或其它控件扩散。

## Risks / Trade-offs

- [标题变大后长标题更易省略] → 保留既有单行省略，避免卡片高度不稳定。
- [状态标签变宽挤压标题] → 标签继续 `flex: 0 0 auto`，标题继续在剩余空间内省略。
- [共享选择器影响详情徽标] → 显式拆分字号，并以测试锁定详情徽标仍为 `9.5px`。

## Migration Plan

纯 CSS 变更，无数据迁移；回滚对应样式与测试即可。
