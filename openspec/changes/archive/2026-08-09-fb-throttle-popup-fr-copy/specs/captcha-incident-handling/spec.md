## ADDED Requirements

### Requirement: Facebook 限流文案识别必须覆盖法语界面的软阻断措辞

边缘与云端两侧的 Facebook 限流文案判据 MUST 覆盖 Facebook **法语界面**的软阻断措辞（「要求先完成一次安全检查才能继续」与「此功能不可用」两句），不得只覆盖既有的英文与中文措辞。

本要求的存在理由：该弹窗的英文界面文案今天已被两侧判据覆盖并触发既定处置，而同一弹窗的法语界面文案零命中——边缘将其判为无事发生、连上报都不发，云端风控状态维持不变并继续按原节奏下发动作。**同一平台阻断因界面语言不同而得到截然不同的处置，是识别覆盖面的缺陷，不是设计意图。**

法语判据 MUST 由**长专属句片段**构成，MUST NOT 包含在 Facebook 正常页面中广泛出现的短语。特别地，判据 MUST NOT 包含违规申诉入口话术（「如果你认为这不违反社群规范，请告知我们」及其等价措辞）——该话术附在一切违规告知之后，包括通知中心里的陈年内容删除通知，把它作为判据会使一条旧通知即可将账号迁入 `restricted`。

判据中指称安全检查的短语 MUST 带有「是必需的 / 被要求」这一限定语义，MUST NOT 使用不带该限定的裸短语——不带限定的同一短语在 Facebook 安全设置页中作为功能名广泛出现。

两仓各自维护的法语词条集合 MUST 逐条一致。两侧 MUST 各有单元测试锁住该集合，使任一侧新增 / 删除词条而另一侧未同步时测试失败——一侧独有的词条会因另一侧不上报而成为永不可达的死代码。

本要求只约束**文案判据的覆盖面与构成纪律**。命中后的处置——信号强度、状态迁移、传输层暂停与恢复、告警类型与冷却——MUST 全部维持现状，MUST NOT 因语言不同而分叉；MUST NOT 新增或改动任何消息类型。

#### Scenario: 法语软阻断弹窗被识别为阻断态

- **WHEN** Facebook 页面出现法语软阻断弹窗，其文案包含「要求先完成一次安全检查才能继续」或「此功能不可用」
- **THEN** 边缘 MUST 将其分类为阻断态并经既有遮罩上报通道上报，MUST NOT 判为无事而静默丢弃

#### Scenario: 法语处置与英语处置等价

- **WHEN** 同一张 Facebook 软阻断弹窗分别以法语界面与英语界面出现
- **THEN** 两者 MUST 得到相同的分类结果、相同的信号强度与相同的风控状态迁移

#### Scenario: 申诉话术不触发限流判定

- **WHEN** 页面文案只包含违规申诉入口话术（「如果你认为这不违反社群规范，请告知我们」），而不包含任何软阻断句片段
- **THEN** 判据 MUST NOT 命中，账号 MUST 维持既有风控状态，MUST NOT 发出限流上报

#### Scenario: 安全设置页的功能名不触发限流判定

- **WHEN** Facebook 法语安全设置页中出现指称安全检查的短语，但不带「是必需的 / 被要求」这一限定
- **THEN** 判据 MUST NOT 命中

#### Scenario: 两仓法语词条集合漂移被测试拦截

- **WHEN** 任一仓的法语限流词条集合被新增或删除，而另一仓未同步
- **THEN** 该仓的单元测试 MUST 失败，使漂移从「无人发现」降级为「测试失败」

### Requirement: 限流文案匹配前的归一化必须消解变音符差异

两侧限流文案判据在匹配前的文本归一化 MUST 消解拉丁字母的变音符差异，使带变音符与不带变音符的同一措辞得到相同的匹配结果。该归一步骤 MUST 与既有的大小写归一、撇号归一、空白折叠并列施加于**判据文本与词条两侧**。

本要求的存在理由：不做变音符归一时，词条字面有三条无法在代码评审中察觉的失配路径——同一字符的预组合形式与组合序列形式字面不相等；文案取证经截图转录时变音符会丢失；同一措辞的地区变体可能标注不同。任何一条命中，判据都会静默空转。

变音符归一 MUST NOT 改变既有英文与中文词条的匹配行为。

词条 MUST 以归一后的形式书写，使词条集合对任一措辞有唯一确定的书写形式。

#### Scenario: 带变音符与不带变音符的同一文案匹配结果一致

- **WHEN** 同一段限流文案分别以带变音符与不带变音符的形式送入判据
- **THEN** 两者 MUST 得到相同的匹配结果

#### Scenario: 预组合与组合序列形式匹配结果一致

- **WHEN** 同一段限流文案分别以 Unicode 预组合形式与组合序列形式送入判据
- **THEN** 两者 MUST 得到相同的匹配结果

#### Scenario: 既有英文与中文判据行为不变

- **WHEN** 既有的英文或中文限流文案送入补入变音符归一后的判据
- **THEN** 匹配结果 MUST 与补入该归一步骤之前完全一致
