## Why

Edge 桌面伴侣界面经过多轮增量功能叠加后，视觉语义出现了三类漂移：交互选中、平台身份和运行状态复用描边与颜色，折叠环境栏形成多层套圈；会话控制悬浮在内容上方，遮挡活动流且脱离“今日进展”的操作上下文；卡片、标题栏、进度与运行说明使用不同圆角、阴影和强调方式，整体不像同一套设计语言。

本次改版需要在不改协议、不改运行状态判断、不增加业务入口的前提下，统一桌面端的信息层级与视觉语义，并保留所有诚实状态、键盘可达性和多环境隔离行为。

## What Changes

- 建立统一的桌面端视觉语义：交互选中使用蓝色，平台色只表达账号平台，绿/琥珀/红/灰等状态色只表达运行结果或需处理程度。
- 正常标题栏回归中性表面；运行说明、发布卡、今日进展和活动流采用一致的柔和表面、边框、圆角和克制阴影。
- 将启动、暂停、恢复、关闭控制收进“今日进展”标题区；六项指标合并为一个分段面板，避免悬浮按钮遮挡活动流。
- 运行中的价值说明由大吉祥物收敛为紧凑的本地图形标记；等待与阶段完成仍可保留静态吉祥物和真实节奏说明。
- 折叠环境栏改为平台实色头像 + 右下角状态点；选中/抬前使用单层蓝色底与短侧标，需要处理只让状态点脉冲，并保留待处理数字徽标。
- 补充桌面 UI 回归断言，锁定生命周期控制位置、平台/状态正交、折叠态状态点以及禁止多层状态环。

## Capabilities

### Modified Capabilities

- `edge-companion-ui`: 统一主窗口视觉层级，并把生命周期控制纳入今日进展上下文。
- `edge-fleet-console`: 重定义折叠环境栏的平台、状态与选中视觉关系。
- `runtime-value-guidance`: 收敛运行态吉祥物占位，同时保持真实阶段说明边界。

## Impact

- `aidcp-edge/src/electron/main.cjs`: Windows 原生标题栏叠加色与新中性标题栏一致。
- `aidcp-edge/src/electron/renderer/index.html`: 今日进展内嵌生命周期控制。
- `aidcp-edge/src/electron/renderer/renderer.js`: 生命周期按钮容器随摘要状态更新。
- `aidcp-edge/src/electron/renderer/styles.css`: 视觉令牌、卡片层级、响应式布局、运行说明和环境栏样式。
- `aidcp-edge/test/electron/*`: DOM、样式与交互回归断言。
- 不改 WebSocket 协议、云端数据形状、环境路由、审批权限或浏览器生命周期语义。
