## Why

慢启动是 Facebook 账号的养号限额能力，但客户端目前也会在小红书环境展示开关，造成能力边界误导；同时现有长文案没有把 7 天曲线的具体数量直接交代清楚，用户无法判断每天会放开到什么程度。

## What Changes

- 慢启动整行仅在当前选中环境明确为 Facebook 时展示；小红书及其他平台不展示开关、状态、说明或帮助入口。
- 将常驻说明改为“开启后头 7 天按曲线逐日放开量，7天后按账号档位运行。”
- 在“慢启动”旁增加可聚焦的问号帮助图标，鼠标悬浮或键盘聚焦时展示 Facebook 7 天每日曲线限额表。
- 表格展示浏览、点赞、评论、关注、发布和加组的每日曲线上限，并明确这些数字是慢启动曲线限额而不是对当天实际执行量的额外承诺。

### Modified Capabilities

- `edge-companion-ui`: 收窄慢启动 UI 的平台可见性，调整常驻说明，并新增可访问的 7 天曲线限额帮助表。

## Impact

- 代码：`aidcp-edge` renderer HTML、CSS、平台感知渲染逻辑与 UI 测试。
- API / 协议：不变；不修改慢启动开关写入、云端配额计算或账号档位。
- 数据：帮助表复制当前云端 `FB_COLD_START_PLANS` 的确定性上界；测试将锁定表格内容，后续修改云端曲线时必须同步客户端说明。
