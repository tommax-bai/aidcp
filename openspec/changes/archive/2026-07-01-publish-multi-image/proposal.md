## Why

当前发布稿件**结构性地只配一张图**：文生图请求写死单张、四层中间产物全是单数 `imageUrl`、落库单列，配图决策角色一次 LLM 调用既定主题又出一条 prompt。图文帖在小红书上允许 1–9 张，单图无法承载"封面→展开→收尾"的图文叙事。本 change 把"按内容配多张图"做出来，同时借机把"决定配几张/画什么"与"把主题写成画图指令"两种不同的活拆成各自可独立配模型、独立失败重试、独立单测的角色。

## What Changes

- **配图决策角色由 2 个拆成 3 个**：现有的"配图决策（既定主题又出 prompt）+ 配图生成"升级为「图集选题（读正文定几张+每张主题）」→「配图指令（主题→万相 prompt）」→「配图生成（并行出图）」。前两个是决策角色、绝不调图源；只有生成角色调图源（延续"决策与执行解耦"红线）。
- **按内容配多张图**：图集选题角色读正文决定张数（默认 3、范围 1–6、硬上限 ≤9）与每张主题；配图指令角色把每个主题翻成一条各不相同的万相 prompt（叙事递进、共享固定风格基底）；去重护栏丢弃近似画面但永远保住封面位，由护栏自身保证"要配图就 ≥1 张"。
- **并行出图 + 每张独立计时（关键正确性修复）**：N 张并行生成（wall-clock ≈ 最慢单张）、对**每张**单独设超时——某张超时只丢该张、不影响其余，**已成功的图绝不被外层总超时整体清零**。修当前"角色级总闸裹整个循环、超时即把已出的图全丢弃→误判无图"的隐患。
- **部分成功诚实语义**：想要 N 张实成 M 张，M≥1 即如实发 M 张（失败那张不补空、不复用别张 URL），M=0 才诚实判失败；上传侧把"任一图失败即整体降级"改为按真实成功上传数 K 记账，K≥1 即有效帖、K=0 才失败；**记账落真实附着张数**。
- **数据模型多图化**：单数 `imageUrl` 升级为 `imageUrls[]`（保留单数派生兼容字段令旧路径零回归）；**复活数据库里早已存在但闲置的 `images TEXT[]` 列**（不新建重复列），保留旧单列双写，新增"真实附着张数"列；迁移 `0017` 纯加列、幂等、可回滚。
- **封面取成功序列首张**：封面选择角色从"单图直选"升级为"读图片数组、恒取首张"；**本期不引入封面索引、不改下发侧 set_cover 触发条件**，把"选非首图当封面 / 真正下发设封面命令 / 边缘设封面页面校准"整体推迟到独立后续 change（默认首图策略恰好绕开尚未校准的边缘设封面操作）。
- **协议与边缘零改动**：边缘"一命令一图"的多图上传通道与云端命令序列已为多图设计好，本 change 复用、不改协议（消息类型集合不变）、不改边缘。

## Capabilities

### New Capabilities
- `publish-multi-image`: 按正文配多张图的能力——张数策略（默认3/范围1–6/上限≤9/下界≥1）、N 张各异主题与 prompt 的规划、并行出图与每图独立计时、部分成功 M/K 诚实语义与真实附着记账、去重护栏保住封面位。

### Modified Capabilities
- `publish-pipeline`: 「配图链路决策与执行解耦」要求从 2 角色（ImagePlanner/ImageGenerator）升级为 3 角色（ImageSetPlanner/ImagePromptComposer/ImageGenerator）；「CoverSelector 选封面」改为消费图片数组、恒取首张；配图链路中间产物由单数 `imageUrl` 改为 `imageUrls[]`。
- `publish-image-required`: 「图文帖无图时诚实失败」的判据从"单图 URL 为空"改为"成功图片数组为空（M=0）"；「配图生成时长可配且充足」补充"并行生成、每图独立计时、总闸 ≈ 每图超时+余量且不得清零已成功图"。

## Impact

- **代码（仅 aidcp-cloud/src/publish-agent）**：新增 2 个决策角色 + 升级生成/封面/组装/执行角色与命令序列降级语义；`types.ts` 中间产物数组化 + 兼容字段；`publish-log-store.ts` 复活 `images` 列、新增附着计数列、双写单列；新增迁移 `migrations/0017`；`prompts.ts` 拆选题/指令两套提示词 + 固定风格基底常量；订正 `image-generator.ts` 陈旧轮询注释。两个新决策角色接入 `role_config`（可后台配模型/温度）。
- **协议 / 边缘 / console**：零改动（多图下发通道与协议已就绪；面板发布历史读侧当前不 select 图片列，多图展示为后续可选项）。
- **环境变量**：新增 `AIDCP_PUBLISH_MAX_IMAGES`、`AIDCP_PUBLISH_PER_IMAGE_TIMEOUT_MS`；`PublishExecutor` 角色超时须随张数上调（覆盖审批等待 + N×单图上传 + 余量）。
- **待坐实（验证任务，非代码改动）**：① 发布命令序列执行期（多图≈N×上传，数分钟）边缘浏览闭环看门狗/SessionMonitor 是否对该边缘暂停判活，避免被误判 idle 杀会话；② N×上传总时长是否落在同账号多节点去重/超时窗口内。未坐实前不下"无需新风控约束"结论。
- **风控/配额**：发帖配额为整帖粒度、与图数无关，多图不新增配额维度；张数上界靠环境变量硬夹守住。
