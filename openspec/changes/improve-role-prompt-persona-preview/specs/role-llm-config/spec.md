## ADDED Requirements

### Requirement: 角色 prompt 预览必须清楚标注人设来源

系统 SHALL 在角色 prompt 只读预览中清楚区分三类内容来源：角色真实 prompt 模板、示例运行时输入、以及人设来源。预览 MUST NOT 把示例运行时输入展示成历史真实调用，也 MUST NOT 把示例人设冒充为某个账号的真实人设。

对浏览侧文本角色，系统 SHALL 在返回体中提供足够的可选元数据，使管理后台能够突出展示本次预览的人设来源：

- 不传 `accountId` 时，预览使用示例人设，返回说明 SHALL 明确“人设为示例人设”。
- 传入已绑定人设的 `accountId` 时，预览使用该账号真实人设，返回说明 SHALL 明确“人设来自所选账号”并回显账号。
- 传入未绑定人设的 `accountId` 时，预览 MAY 仍使用示例人设渲染供查看，但 MUST 设置回落标志并明确“该账号运行会被拒绝，当前展示为示例人设”，不得标成该账号真实人设。
- 无论人设来源为何，实时卡片、正文、评论、标题等运行时输入仍 SHALL 以示例占位标注。

当角色实现人设来源分段时，分段 MUST 与渲染后的 prompt 逐字匹配；无法唯一匹配时系统 SHALL 回落为扁平展示，不得伪造高亮。现役浏览角色的人设分段实现 SHOULD 与其 `buildPrompt()` 使用同一字段集合和同一文本标签，避免正常角色长期丢失高亮。

#### Scenario: 未选择账号时明确显示示例人设

- **WHEN** 管理后台请求某浏览侧文本角色 prompt 预览且不传 `accountId`
- **THEN** 返回体说明人设来源为示例人设，实时输入仍标注为示例占位，前端突出展示“示例人设”

#### Scenario: 选择已绑定账号时突出显示账号人设

- **WHEN** 管理后台请求某浏览侧文本角色 prompt 预览并传入已绑定人设的 `accountId`
- **THEN** prompt 使用该账号真实人设渲染，返回体回显账号并说明人设来自所选账号，前端在 prompt 正文上方突出展示该来源

#### Scenario: 选择未绑定账号时诚实回落

- **WHEN** 管理后台请求某浏览侧文本角色 prompt 预览并传入未绑定人设的 `accountId`
- **THEN** 返回体设置回落标志，说明该账号运行会被拒绝且当前展示为示例人设，前端不得把示例人设标成该账号真实人设

#### Scenario: 精选准入正文评估可以高亮人设段

- **WHEN** 管理后台请求 `browse:curated_note_evaluator` 的 prompt 预览
- **THEN** 返回的 prompt 来源分段包含 `persona` 段，且各段拼接逐字等于完整 prompt；正文、标题等运行时字段仍以示例占位显示

#### Scenario: 分段不匹配时不伪造高亮

- **WHEN** 某角色的人设片段无法在渲染后的 prompt 中唯一定位
- **THEN** 系统返回扁平 prompt 或不附来源段，不得生成不真实的人设高亮
