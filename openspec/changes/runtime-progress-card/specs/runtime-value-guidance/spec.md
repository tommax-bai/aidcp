## MODIFIED Requirements

### Requirement: 详细浏览步骤不得与价值进度争夺主视图

Edge 客户端 SHALL 仅用探索进度卡内的三段价值流程解释当前推进状态，MUST NOT 在主视图或探索进度卡中提供“查看运行步骤”或“收起运行步骤”入口，也 MUST NOT 保留可展开的七段详细浏览步骤。该约束 SHALL 同时适用于运行中、场次间隔、小时间隔和今日完成状态。

#### Scenario: 各状态只展示三段价值流程
- **WHEN** 探索进度卡处于运行中、场次间隔、小时间隔或今日完成状态
- **THEN** 卡片展示与该状态匹配的三段价值流程
- **AND** 页面不存在“查看运行步骤”或“收起运行步骤”入口
- **AND** 页面不存在可展开的七段详细浏览步骤

#### Scenario: 动态连接线匹配卡片语义
- **WHEN** 三段价值流程之间展示动态连接线
- **THEN** 运行中连接线使用蓝色语义，场次/小时间隔使用青色语义，今日完成使用绿色语义
- **AND** 滑动圆点的可见行程覆盖完整连接线后再复位
