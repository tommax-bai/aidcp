## Why

桌面客户端左侧「环境栏」（`.env-rail`）当前只有下界没有上界（`min-height: calc(100vh - 46px)`，无 `height` / `max-height`），栏高随环境行数增长。后果：

- 环境一多，整栏把**整页**撑高 → 滚动的是文档而不是列表，右侧主区域跟着一起滚。
- 栏底动作区（「引导处理」/「全部启动」/ 提示行）被列表挤到折叠线以下，需要滚动整页才够得着。
- `.rail-list` 上写了 `overflow-y: auto`，但父容器高度由内容决定，滚动条**从未真正生效**（形同虚设）。

运维在多环境（fleet）下的实际动作是「在一列账号里挑一个」，期望的是微信选联系人那种手感：**列表固定在一屏内、超出就在栏内滚动**，栏头栏底始终在手边。

## What Changes

- 环境栏改为**固定高度**（标题带以下满屏高），随主区域滚动时**留在原位**；只有环境列表区域内部滚动。
- 栏头（环境计数 / 添加 / 收起）与栏底动作区常驻可见，不再被列表挤走。
- 列表滚动与右侧主区域**滚动链隔离**（滚到底不再带着整页走）。
- 分组标题（需处理 / 运行中 / 离线…）在列表内**吸顶**，滚动时始终知道当前处在哪一组。
- 细滚动条 + 收起态 / 展开态同等适用。
- 状态刷新触发的列表重绘**保持滚动位置**（今天 `innerHTML` 全量重建，一旦列表真能滚，任何状态变化都会把用户甩回顶部）。
- 选中环境变化（引导流自动前进、启动恢复上次选中）时把该行**滚入视野**；用户手动滚动期间不强行拉回。
