## ADDED Requirements

### Requirement: 拆分前盘点范围覆盖六类状态，含非表非内存的进程外状态

服务拆分的盘点范围 SHALL 覆盖六类状态，MUST NOT 只盘「进程内状态、事件、Store 和每张表」这四类：

1. 进程内状态与其宿主；
2. 进程内事件总线上的事件；
3. 数据访问对象与其拥有的每张表；
4. **本机文件系统信号与共享路径**（以本机路径为事实源的授权凭证、清单、基址等）；
5. **本机进程内锁与内存事实表**（配置内存镜像、运行时事故表等既非表也非事件的运行时事实）；
6. **数据库级 advisory lock**（按 key 命名空间登记全部引用点）与**常驻定时任务**（定时器宿主及其扫描 / 写入的表）。

每条盘点行 MUST 至少含：引用点 `文件:行`、拆分后归属服务、是否跨服务边界、跨服务时的替代机制、以及不替代会怎样失效。失效描述 MUST 写出**失效方向**——是报错还是静默。盘点 MUST NOT 以「暂时同机所以还能工作」为由略过任何跨边界项。

#### Scenario: 本机文件信号被盘出并登记替代机制
- **WHEN** 对某跨服务边界的功能做拆分前盘点
- **THEN** 以本机文件承载的授权凭证、清单或基址被列为盘点行，标注归属服务、替代机制与「静默失效」方向，MUST NOT 因为当前同机可用而不登记

#### Scenario: 常驻定时任务被逐个定位归属
- **WHEN** 盘点常驻定时任务
- **THEN** 每个定时器宿主被登记其扫描与写入的表、拆分后归属服务与执行目标归属；同一任务 MUST NOT 在两个服务里各跑一份

#### Scenario: 红线反例——盘点漏掉进程外本机状态（禁止）
- **WHEN** 盘点结论只覆盖进程内状态、事件、Store 与表
- **THEN** MUST 视为盘点未完成；本机文件信号、本机锁、库级 advisory lock 与常驻定时任务在结构上不属于这四类，遗漏它们的拆分会以静默方向失效

### Requirement: advisory lock 的 key 命名空间只能被单一服务引用

数据库级 advisory lock 的每个 key 命名空间 SHALL 只被单一服务边界内的源码引用。跨服务的互斥 MUST NOT 用 advisory lock 表达——一旦两侧连接到不同数据库或不同实例，两侧各自加锁均会成功、互斥消失且不产生任何错误。需要跨服务串行时，MUST 把写点收敛到数据所有者服务，由该服务在与被保护数据同库的事务内用行级锁或等价机制串行化。系统 MUST 有自动化检查在 advisory lock key 被跨服务边界引用时失败；单服务内使用的 key MUST 在检查中显式登记。

#### Scenario: 跨边界共用锁被替换为所有者串行
- **WHEN** 某 advisory lock key 同时被未来的两个服务引用
- **THEN** 该锁的跨界用法 MUST 被替换为「写点收敛到数据所有者 + 所有者事务内行级锁」，替换后锁与被保护数据仍在同一数据库

#### Scenario: 自动化检查拦住新的跨界引用
- **WHEN** 有改动让某 advisory lock key 出现在第二个服务边界目录内
- **THEN** 自动化检查失败并指出该 key 与两处引用点，MUST NOT 只靠人工评审发现

#### Scenario: 红线反例——靠部署纪律保证同库（禁止）
- **WHEN** 有方案主张保留跨服务 advisory lock、靠「两个服务始终连同一个库」的部署纪律来保证互斥
- **THEN** MUST 视为违规、不予合入；一次拆库、一次读写分离或一次连接指向副本即让互斥静默消失

### Requirement: 跨服务授权凭证、锁与事实源禁止走共享本机资源

跨服务的授权凭证、互斥锁与事实源 MUST NOT 经共享本机文件系统、共享本机路径或进程内内存传递。这些通道在同机部署时可用、在分机 / 容器化 / 私有临时目录下静默失效，且失效方向通常是 fail-closed 的停滞而非报错，最难被发现。跨服务传递 SHALL 只用持久记录、持久命令 / 事件、或有超时与诚实错误的窄内部接口。

#### Scenario: 私有临时目录不改变授权行为
- **WHEN** 服务单元启用私有临时目录，或写方与读方被部署到不同主机
- **THEN** 授权链路行为不变，因为授权不经本机路径传递

#### Scenario: 红线反例——用共享目录做跨服务互斥（禁止）
- **WHEN** 有实现用本机文件的排他创建在两个服务之间做互斥
- **THEN** MUST 视为违规、不予合入
