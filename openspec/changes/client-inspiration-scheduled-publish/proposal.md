## Why

客户端稿件审核页目前只展示 Cloud 推送的最新一条待审稿；同一账号有多条候选稿时，其余稿件不可达。批准动作也只能沿用稿件既有发布方式，客户无法在审批时选择小红书原生定时发布。需要把审核页升级为完整的待审工作区，并把发布时间选择放到真正授权发布的批准位置。

## What Changes

- 保持灵感库“参考创作”入口原样，不在排队洗稿时设置发布时间。
- 将客户端稿件审核页升级为账号范围的多稿待审列表；多条时使用类似灵感池的卡片网格、摘要与详情钻取，单条时可直接进入详情。
- 在客户鉴权域新增当前环境绑定账号的待审稿列表/详情只读接口，提供稳定分页、最小披露 DTO、账号隔离和旧版单稿推送回落。
- 在稿件详情的批准位置增加“立即发布 / 定时发布”选择；定时使用北京时间分钟值并显示未来 1 小时至 14 天约束。取消稿件不要求发布计划。
- 扩展客户端审批具名 IPC 与 `publish.approval_action` 协议：Cloud 权威校验发布计划，必要时通过既有 `editDraft` 内容版本 CAS 更新同一稿件，再以新版本写审批授权并触发下发。
- 批准/取消成功后只移除已处理稿件并返回剩余待审列表；不得因处理一条而关闭或覆盖其它待审稿。

### Modified Capabilities

- `edge-companion-ui`: 稿件审核页支持多条待审稿的卡片列表/详情导航，并在批准位置选择立即或定时发布。
- `client-customer-auth`: 为已授权环境提供账号隔离、分页且最小披露的待审稿列表与详情读接口。
- `xhs-native-scheduled-publish`: 客户端审批可在版本闸内设置合法定时计划后授权，同一动作不得静默降级或批准错误版本。

## Impact

- `aidcp-edge`: Electron main/preload 具名客户 API 桥、内容工作区稿件列表/详情/审批 UI、审批 RPC 参数校验和相关测试。
- `aidcp-cloud`: customer-auth 待审稿读接口、发布记录待审分页投影、审批动作处理、协议类型与测试。
- `aidcp`: OpenSpec delta 与 `docs/protocol.md`。
- 无数据库迁移，不改变参考创作任务创建 DTO，不新增自动审批，不构建 Electron 安装包。
