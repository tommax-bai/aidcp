## ADDED Requirements

### Requirement: Create environment UI exposes OS families instead of fixed machine templates

The desktop shell's create-environment panel SHALL expose an OS-family selector for AdsPower profile creation. It MUST NOT present the selection as one of a small fixed set of complete machine templates, because the remaining fingerprint details are generated by AdsPower during `user/create`. The selected OS family SHALL be the only fingerprint-shape choice submitted by the renderer for ordinary single creation.

#### Scenario: single creation submits OS family
- **WHEN** the operator opens the create-environment panel
- **THEN** the creation selector offers supported OS families such as Windows and macOS
- **AND** selecting one and confirming submits an OS-family key rather than a fixed machine-template key

#### Scenario: batch mode hides the OS-family selector
- **WHEN** the operator selects Facebook batch creation
- **THEN** the OS-family selector is hidden
- **AND** the main process assigns OS families independently for each account
