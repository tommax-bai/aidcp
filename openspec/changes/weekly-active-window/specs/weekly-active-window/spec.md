## ADDED Requirements

### Requirement: 全局可活跃时间按周历（天 × 小时）可配置、热加载、缺值绝不 brick

系统 SHALL 提供一个**全局「可活跃时间」周历闸**：以**周 × 天 × 小时**（7 天 × 24 小时 = 168 格）表达「允许活跃」的时段，每格取值「活跃 / 休眠」，对**所有账号**生效。配置 SHALL 作为**全局单例落库**（复用 `session_config_global` 单行表，加一列定长 168 的 '0'/'1' 掩码串，周内天 0=周一 … 6=周日、按服务器本地时间），管理后台「安全」页可改、运行时每次现读（热加载、无需重启）。掩码缺失（列 NULL / 未配置）或非法（长度 ≠ 168、含非 '0'/'1' 字符）MUST 回落为「全周全天活跃 = 不限」（**绝不 brick、严格零回归**）。写入校验：传则必须为长度 168、仅含 '0'/'1' 的串，非法 MUST 整块拒（4xx / `invalid_value`），MUST NOT 部分落库或假成功。配置的存储与编辑 MUST NOT 触碰风控状态单写路径。

本闸与既有 `session-auto-resume` 的**单段日活跃时段窗口并存且相互独立**：两道闸都判「可活跃」时才活跃（更严者生效）；本闸表达力更细（按天按小时挖空）、且额外约束「开新会话」与「运行中会话」（日窗口仅约束续场）。

#### Scenario: 未配置回落全天活跃（零回归）

- **WHEN** 全局单场配置表无掩码列值（全新部署 / 迁移刚跑完 / 从未设过）
- **THEN** 「可活跃时间」判定为全周全天活跃（不设闸），开会话 / 续场 / 运行中行为与未引入本特性逐位一致

#### Scenario: 配置合法掩码下场会话即生效

- **WHEN** 运营在「安全」页保存一个合法的 168 格周历掩码（如工作日 09:00–22:00 活跃）
- **THEN** 所有账号的下一次「开会话 / 续场 / 运行中跨界判定」即按新掩码生效（热加载、无需重启），后台回显为「已配置」并显示活跃小时数

#### Scenario: 非法掩码整块拒、不落库

- **WHEN** 提交的掩码长度 ≠ 168 或含非 '0'/'1' 字符
- **THEN** 服务端整块拒（`invalid_value` / 400），MUST NOT 部分落库或假成功，内存生效值保持改前真态

### Requirement: 可活跃时段外不开新会话、不自动续场

当前服务器本地时刻落在「休眠」格时，云端 MUST NOT 开启新的浏览会话——该约束 SHALL 收口于会话(重)启动的统一入口，覆盖**边端 hello 重连、绑人设自动开跑、自动续场、面板手动启动**全部路径；同时自动续场闸 MUST 新增「可活跃时间」一道（与既有日活跃窗口、每日上限、风控状态闸并列），任一不过则本轮诚实不续、不报错。落在「活跃」格时，开会话 / 续场行为不受本闸影响。掩码缺失 / 非法时本闸视作全开（不拦）。

#### Scenario: 休眠时段边端重连不开会话

- **WHEN** 边端 hello 到达（账号已绑人设、调度全局开），但当前本地时刻落在掩码的休眠格
- **THEN** 云端 MUST NOT 开启浏览会话、MUST NOT 发巡刷信号，保持休眠（采登录账号真实昵称等登录引导步骤不受本闸约束、按既有路径）

#### Scenario: 休眠时段不自动续场

- **WHEN** 单场正常结束、休息到点尝试续场，但此刻落在休眠格
- **THEN** 续场闸不过，云端 MUST NOT 自动续场；待进入活跃格且边端重连 / 下一次 hello 时方可再起

#### Scenario: 活跃时段正常开/续

- **WHEN** 当前时刻落在活跃格
- **THEN** 本闸放行，开会话 / 续场按既有其余闸（调度开关 + 人设 + 风控 + 日窗口 + 每日上限）正常进行

### Requirement: 会话运行中跨入休眠时段须结束当前会话

一场已在运行的浏览会话，当服务器本地时刻**跨入**掩码的休眠格时，云端 MUST 结束当前会话（走既有正常结束流程，与时长 / 动作数 / 配额 / idle 同类）。判定 SHALL 由会话监测体每次检查时现读全局掩码（热加载）。**通知巡视等暂停期 MUST NOT 被打断**——暂停期延期结束判定，待巡视结束恢复后再据此结束。掩码缺失 / 非法时不触发此结束。会话因此结束后，续场侧会被「可活跃时间」续场闸同样挡住，故窗口外不会立刻重开。

#### Scenario: 运行中跨入休眠即结束

- **WHEN** 会话进行中、本地时刻从活跃格跨入休眠格（如窗口配到 22:00、当前到 22:00）
- **THEN** 会话监测体在下次检查时判定结束，云端走正常结束流程结束当前会话

#### Scenario: 巡视暂停期不被打断

- **WHEN** 跨入休眠格的时刻恰逢通知巡视（监测体时钟暂停）进行中
- **THEN** 不在巡视中途结束会话；待巡视结束、监测体时钟恢复并补检查时，再据「可活跃时间」结束
