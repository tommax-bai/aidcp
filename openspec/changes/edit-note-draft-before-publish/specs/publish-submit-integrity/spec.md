## ADDED Requirements

### Requirement: 可见范围可编辑但绝不被编辑清空或改为非法值

当可见范围（visibility）经待审草稿编辑通路变为可编辑时，编辑侧 MUST 校验其为**非空且属已知合法枚举**，任何会把可见范围置空或改为未知值的编辑 MUST 被拒（`missing_visibility` / 非法字段），MUST NOT 被持久化。元数据深合并 MUST 在可见范围未被改动时逐字保留原值。由此「硬必选元数据缺失判致命」的既有不变量在引入编辑后仍然成立——绝不因编辑而落库一条无可见范围的草稿。

#### Scenario: 编辑合法可见范围
- **WHEN** 运营把可见范围改为一个已知合法枚举值
- **THEN** 编辑成功、深合并只更新该项，其余元数据键逐字保留

#### Scenario: 拒绝清空可见范围
- **WHEN** 编辑试图把可见范围置空或改为未知值
- **THEN** 编辑被拒（`missing_visibility` / 非法字段）、不持久化，绝不落库一条无可见范围的草稿

#### Scenario: 未改动则逐字保留
- **WHEN** 编辑请求未携带可见范围
- **THEN** 深合并逐字保留原可见范围，硬必选致命闸不受影响
